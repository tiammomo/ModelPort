# ModelPort 精炼与易用性审查

审查基线：`fa2b510`，2026-09-06。投入决策见
[ADR-0008](adr/0008-team-gateway-focus-and-task-navigation.md)，后续顺序由
[路线图](ROADMAP.md)维护。本文记录本轮实现与验证边界，避免重复维护产品规划。

## 已处理的问题

| 范围 | 发现与改动 |
| --- | --- |
| 安装与配置 | 入门依赖尚不存在的标签；TOML 监听地址覆盖容器地址；外部数据库仍要求内部密码。统一源码安装路径，支持环境监听地址覆盖，修正外部数据库检查。 |
| 首次配置 | 新用户需要面对完整环境参考并手填多份密码。新增幂等初始化脚本，生成最小环境文件和互相独立的凭证；保留现有配置，Secret 文件权限为 0600。 |
| 接入与策略 | 手写项目 JSON、管理员目录与实际密钥范围不一致。改用审计策略表单及按密钥的只读预检；未知数据保持本地限制。 |
| 引导与证据 | 六项清单分散；HTTP 200 可能来自随后失败的流。提供四步引导和已保存状态恢复，仅完整成功请求算完成；日志可直接定位同一请求的账本证据。 |
| 导航与会话 | 11 个一级入口；重复会话初始化可能二次清空正在使用的查询。收敛为 5 个任务组，保留 URL 和角色权限，合并并发会话检查。 |
| 浏览器体验 | 登录会提前加载图表依赖；多处复制实现不一致，失败可能显示成功。恢复按页面加载图表，统一复制结果和临时文本清理。 |
| 代码维护 | 模型页的适配草稿与其他操作状态交织；可选运维查询集中在核心账本。拆出自持草稿的模型适配对话框及运维查询模块，保留事务和外部接口。 |
| 默认负担 | 无引用依赖和默认构建 Agent。移除 date-fns、framer-motion，解决 npm 审计项；Agent 构建改为显式开启，发布与 workspace 验证继续覆盖。 |
| 文档 | 入门、策略示例、发布路径多处复制。压缩中英文 README，详细操作统一链接到维护中的参考文档，合并重复 Changelog 标题。 |

## 测量方法

- 一级管理员入口：11 → 5；默认本地镜像：3 → 2。
- 两轮改动间，登录页面的静态 JavaScript 依赖闭包（包含 LoginPage，逐文件计算，
  不包含仪表盘动态模块）已从约 999 KB 降至约 605 KB；这是构建产物测量，
  不等于实测网络加载耗时。最终数值以候选版本的构建验证为准。
- 第一轮干净安装 `node_modules` 净减少约 4.7 MiB；第一轮 `dist` 略增。
  新交互和测试会增加部分源码，不能将文件移动或删除测试计为体积收益。
- README 英文从 254 行降到 115 行，中文从 228 行降到 102 行；高级功能
  的配置参考仍保留。模型页拆出约 275 行，可选运维查询独立约 900 行。

## 验证边界

按[开发验证矩阵](DEVELOPMENT.md)执行 Rust 格式、workspace 测试和 Clippy，
前端类型、Lint、单元测试、生产构建、完整 Playwright，PostgreSQL 迁移、
原子准入和运维查询回归，acceptance、ShellCheck、文档链接和 Compose 渲染。
本地聚合检查已通过：475 项 Rust 测试、125 项前端测试；21 项浏览器用例通过，
其中 Provider 管理使用显式合成凭证补全隔离测试目录。初始化检查覆盖权限、
凭证独立性和不覆盖既有文件。发布前继续执行正式镜像
构建、实际 Compose 启动与同源 smoke，并等待远端 CI。

使用隔离数据库和合成凭证；测试中的模型请求指向关闭的本地端口，没有验证
真实付费上游。预检不证明来源 IP、实时配额、上游健康或完整客户端能力，
成功必须由实际请求及终态证据确认。

本轮未改写流式协议、预算事务、审计与恢复契约，也未引入新运行时服务。
更细的预算/请求存储拆分仍按维护需求单独评估。GPU inventory、Deployment
生命周期及调度继续遵守已批准的需求门槛。真实团队的接入耗时和留存未测量，
不据此宣称产品价值已经获得用户验证。
